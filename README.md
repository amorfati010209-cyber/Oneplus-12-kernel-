# Kali NetHunter Kernel OnePlus 12 (SM8650) — Android 16

Этот репозиторий подготовлен для сборки ядра OnePlus 12 с поддержкой функций Kali NetHunter.

## Статус проекта
- **База:** Официальное ядро OnePlus SM8650 (Android 16 / OxygenOS 16).
- **Поддержка NetHunter:** Включены базовые конфигурации (`configs/nethunter.config`).
- **Сборка:** Автоматизирована через `build.sh` и GitHub Actions.

## Подготовка к сборке

### Патчи исходного кода
Для полной поддержки NetHunter (HID Attacks, Wi-Fi Injection) требуются специфические патчи для ядра 6.1.
- Поместите ваши `.patch` файлы в папку `patches/`. Скрипт `build.sh` применит их автоматически перед началом компиляции.

### Конфигурация ядра
Базовые опции (HID, MAC80211) уже добавлены в файл `configs/nethunter.config`. Вы можете редактировать этот файл для добавления своих драйверов.

## Как собрать ядро

### Сборка через GitHub Actions
1. Перейдите во вкладку **Actions**.
2. Выберите **Build OnePlus 12 Kernel**.
3. Нажмите **Run workflow**.

**Важно:** Исходный код ядра занимает более 100 ГБ. Стандартные серверы GitHub имеют ограничения по памяти. Скрипт включает очистку диска, но для полной сборки всех модулей может потребоваться Self-hosted runner или платная версия GitHub Actions с увеличенным диском.

### Сборка локально
1. Установите `repo` и зависимости.
2. Подготовьте код: `./setup_env.sh`
3. Соберите: `./build.sh`
